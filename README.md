# JONR P20 Pro WEB

JONR P20 Pro 로봇청소기(`xtl.vacuum.xm2216`)를 PC에서 실행하는 **로컬 웹 대시보드**입니다.

Mi Home 앱 대신 같은 네트워크에서 로봇을 제어하고, 지도·청소 경로·카펫·금지구역·문턱을 웹 화면에서 관리할 수 있습니다. 서버는 PC의 `127.0.0.1`에만 열리며, 토큰과 설정은 사용자 PC에만 저장됩니다.

> 이 프로젝트는 JONR, Xiaomi, Mi Home과 무관한 비공식 프로젝트입니다.

---

## 1. 사용 환경

- **로봇**: JONR P20 Pro (`xtl.vacuum.xm2216`)
  - 개발·확인 펌웨어: `4.5.6_0805`
- **PC**: Windows / macOS / Linux
- **Python**: 3.10 이상 (3.13에서 확인)
- **네트워크**: 로봇과 PC가 같은 공유기(LAN/Wi-Fi)에 연결
- **Mi Home 계정**: 토큰 추출 및 지도 클라우드 세션에 필요

공유기에서 로봇의 MAC 주소에 **IP를 고정(DHCP 예약)** 해 두는 것을 권장합니다. 로봇 전원을 껐다 켜면 IP가 바뀔 수 있습니다.

## 2. 설치

### 2-1. Python 설치

Python 3.10 이상을 설치하고 `python` 명령이 동작하는지 확인합니다.

```

### 2-2. 프로젝트 받기

```

ZIP으로 받았다면 압축을 풀고 해당 폴더로 이동합니다.

### 2-3. 가상환경과 의존성 설치

```powershell

pip install -r requirements.txt

python3 -m venv .venv

```

## 3. 최초 설정 (한 번만)

로봇 제어에는 **IP**, **32자리 토큰**, **DID**와 지도 표시용 **클라우드 세션**이 필요합니다. 아래 명령 하나로 모두 받아옵니다.

```powershell
python app.py --setup
```

- Mi 계정 ID와 비밀번호를 입력합니다.
- 캡챠나 2FA 코드가 요청되면 안내에 따라 입력합니다.
- `xtl.vacuum.xm2216` 기기를 찾은 서버 목록이 표시됩니다.
- 적용할 서버를 입력합니다. **대소문자를 구분하지 않으며**, 서버가 하나뿐이면 Enter로 기본값을 선택할 수 있습니다.
- IP / 토큰 / DID / 서버는 `config.json`에, 클라우드 세션은 `.xc_session.json`에 자동 저장됩니다.

별도로 `token_extractor.py`를 내려받거나 직접 실행할 필요는 없습니다. 앱이 고정된 커밋과 SHA256으로 검증한 뒤 사용합니다.

> 토큰과 계정 비밀번호는 절대 채팅, 이슈, 저장소에 올리지 마세요.

---

## 4. 실행

```powershell
python app.py
```

`--setup`으로 세션과 설정을 저장했다면 추가 로그인 없이 바로 시작됩니다. 실행할 때 저장된 세션이 만료된 것으로 감지되면, 터미널에서 바로 재로그인을 요청합니다. 백그라운드 실행처럼 입력을 할 수 없는 상황에서는 `python app.py --login` 안내만 출력하고 서버를 시작합니다. 세션을 갱신하거나 서버를 다시 지정하려면:

```powershell
python app.py --login
```

로그인을 건너뛰어도 로컬 제어는 가능하지만, 지도·청소 경로 등 클라우드 지도 기능은 동작하지 않을 수 있습니다.

서버가 시작되면 브라우저에서 접속합니다.

```text
http://127.0.0.1:5000
```

## 5. 연결 설정

`--setup`에서 IP / 토큰 / DID / 서버가 이미 저장되므로, 설정 창은 값을 **변경할 때만** 사용하면 됩니다. 우측 상단 **⚙ 설정** → **연결 설정**에서 원하는 값을 수정하고 **저장**을 누르세요.

저장 후 상태가 자동으로 갱신됩니다. 저장된 토큰은 보안상 화면으로 다시 내려보내지 않습니다. 토큰 입력란은 비어 있으며, **변경하지 않고 저장하면 기존 토큰이 유지**됩니다. 새 토큰을 사용할 때만 32자리 값을 입력하세요.

`config.json`은 앱이 자동으로 생성하며, 토큰이 평문으로 저장됩니다. 이 파일은 `.gitignore`에 포함되어 있으므로 저장소에 올라가지 않습니다.

## 6. 주요 기능

- 실시간 상태, 배터리, 청소 면적·시간
- 전체 청소 / 방 청소 / 구역 청소
  - 청소 중인 모드는 기기 보고값(17.9 clean-type-status)으로 감지해 해당 탭으로 자동 전환됩니다.
  - 청소 중에는 방 선택·구역 생성이 잠기며, 진행 중인 대상은 기기 보고값(17.34 clean-values)에서 읽어 앱 재시작 후에도 표시됩니다.
- 청소 모드, 흡입력, 물걸레 습도, 청소 횟수, 청소 경로 설정
- 지도 뷰어, 로봇 위치, 청소 경로 표시
- 가상벽·진입금지 구역, 물걸레 금지 구역
- 카펫 등록 및 카펫별 청소 전략
- 문턱(미닫이 문턱 / 문지방) 등록
- 로봇 설정(카펫, 물걸레 확장, 차일드락, 청소금지 시간, 음성)
- 스테이션 설정(물걸레 세척 간격, 열풍 건조, 자동 먼지 비움)
- 걸레 세척 / 건조 / 먼지 비움 버튼은 Mi 클라우드 경유로 전송됩니다. (로컬 miIO는 응답만 주고 실제 동작하지 않음)
- 소모품 사용률 확인 및 수명 초기화
- 시스템 / 라이트 / 다크 테마

## 7. 미구현 기능

이 기능들은 구현할 예정이 없으므로, 공식 앱에서 직접 컨트롤하세요:
- 지도 관리
  - 지도 저장 모드, 복층 모드, 지도의 방 관리나 커스텀 설정, 이름 변경 등
- 청소 예약
- 원격 제어 모드
- 펌웨어 관리
- Mi home 관련 기능
  - 기기 공유
  - 위치 관리
  - 보안 설정
- 알림 (브라우저 알림)
  - Mi Home에서 표시되는 “청소 완료”, “오수 탱크를 즉시 청소”, “선택한 구역을 찾을 수 없음” 같은 알림은 구현하지 않습니다.
  - 공식 플러그인도 푸시를 직접 만들지 않고, Mi Home 앱의 네이티브 MIoT SDK가 받은 클라우드 푸시를 `DeviceEventEmitter`로 구독할 뿐입니다.
  - 웹앱에서 같은 푸시를 받으려면 문서화되지 않은 Xiaomi 클라우드 푸시 프로토콜을 별도로 재구현해야 해서 현실적으로 어렵습니다.
  - 기기 프로퍼티(`17.36 message`)를 빠르게 폴링하는 방식도 시도했지만, 이 알림은 프로퍼티 값으로 남지 않아 수신할 수 없었습니다.

모바일 포팅 또한 구현 계획 없습니다.

## 9. 경고

- **비공식 프로젝트입니다.** JONR, Xiaomi, Mi Home과 제휴하거나 보증받은 프로젝트가 아닙니다.
- **토큰은 로봇을 완전히 제어할 수 있는 자격 증명입니다.** `config.json`, `.xc_session.json`, 화면 캡처, 터미널 로그를 공유하지 마세요.
- 서버는 `127.0.0.1`에만 바인딩되며, Host·Origin·요청 헤더를 검사해 다른 사이트에서의 호출을 차단합니다. 포트를 외부에 노출하거나 리버스 프록시 뒤에 두지 마세요.
- 지도·청소 경로·카펫·문턱 저장은 **실제 기기 설정을 변경**합니다.
- 클라우드 지도 기능은 Mi 클라우드 정책, 네트워크 상태, 계정 세션에 의존합니다. 세션이 만료되면 `python app.py --login`을 다시 실행해야 합니다.
- 로봇 모델과 펌웨어 버전에 따라 일부 기능이 동작하지 않거나 다르게 표시될 수 있습니다.
- **이 프로젝트의 코드는 100% AI에 의해 작성되었습니다.** 실제 기기에서 사용하기 전에 코드와 동작을 충분히 검토하세요.
- 소프트웨어는 **있는 그대로(AS IS)** 제공되며, 사용으로 인한 기기 오작동·설정 손실·데이터 손실에 대해 보증하지 않습니다.
