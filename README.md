# JONR P20 Pro WEB

JONR P20 Pro 로봇청소기(`xtl.vacuum.xm2216`)를 PC에서 실행하는 **로컬 웹 대시보드**입니다.

Mi Home 앱 대신 같은 네트워크에서 로봇을 제어하고, 지도·청소 경로·카펫·금지구역·문턱을 웹 화면에서 관리할 수 있습니다. 서버는 PC의 `127.0.0.1`에만 열리며, 토큰과 설정은 사용자 PC에만 저장됩니다.

> 이 프로젝트는 JONR, Xiaomi, Mi Home과 무관한 비공식 프로젝트입니다.

---

## 1. 사용 환경

- **로봇**: JONR P20 Pro (`xtl.vacuum.xm2216`)
  - 개발·확인 펌웨어: `4.5.6_0805`
- **PC**: Windows / macOS / Linux
- **Python**: 3.10 이상 (3.13에서 확인)
- **네트워크**: 로봇과 PC가 같은 공유기(LAN/Wi-Fi)에 연결
- **Mi Home 계정**: 토큰 추출 및 지도 클라우드 세션에 필요

공유기에서 로봇의 MAC 주소에 **IP를 고정(DHCP 예약)** 해 두는 것을 권장합니다. 로봇 전원을 껐다 켜면 IP가 바뀔 수 있습니다.

## 2. 설치

### 2-1. Python 설치

Python 3.10 이상을 설치하고 `python` 명령이 동작하는지 확인합니다.

```powershell
python --version
```

### 2-2. 프로젝트 받기

```powershell
git clone https://github.com/iwj9/JONR-P20-Pro-WEB.git
```

ZIP으로 받았다면 압축을 풀고 해당 폴더로 이동합니다.


## 3. 토큰·IP·DID 확인

로봇 제어에는 **IP**, **32자리 토큰**, **DID**가 필요합니다. Mi Home 계정으로 한 번 추출합니다.

```powershell
curl.exe -sL "https://raw.githubusercontent.com/PiotrMachowski/Xiaomi-cloud-tokens-extractor/d8bb6a9e6aeff2d38ecc9e4caefcc58f8551e672/token_extractor.py" -o "$env:TEMP\token_extractor.py"
python "$env:TEMP\token_extractor.py"
```

- Mi 계정 ID와 비밀번호를 입력합니다.
- 조회할 서버를 묻으면 비워 두면 전체 서버를 확인합니다. 한국 계정은 보통 `sg` 또는 `de` 계열에서 발견됩니다.
- 출력에서 `xtl.vacuum.xm2216` 행의 **IP / TOKEN / DID / MAC**을 확인합니다.

> `token_extractor.py`는 이 프로젝트가 아닌 외부 도구입니다. 토큰과 계정 비밀번호는 절대 채팅, 이슈, 저장소에 올리지 마세요. 앱은 로그인 시 이 파일을 고정된 커밋과 SHA256으로 검증한 뒤 사용합니다.

## 4. 실행

```powershell
python app.py
```

첫 실행 시 지도 표시를 위해 **Mi 클라우드 로그인**을 한 번 요청합니다. 터미널 안내에 따라 Mi 계정으로 로그인하면 세션이 `.xc_session.json`에 로컬 저장됩니다.

- 자동 로그인 안내가 뜨지 않거나 세션이 만료됐다면:

```powershell
python app.py --login
```

- 로그인을 건너뛰어도 로컬 제어는 가능하지만, 지도·청소 경로 등 클라우드 지도 기능은 동작하지 않을 수 있습니다.

서버가 시작되면 브라우저에서 접속합니다.

```text
http://127.0.0.1:5000
```

## 5. 연결 설정

1. 우측 상단 **⚙ 설정**을 엽니다.
2. 맨 아래 **연결 설정**에 위에서 확인한 값을 입력합니다.
   - 청소기 IP
   - Token (32자리)
   - DID
3. **저장**을 누릅니다.

저장 후 상태가 자동으로 갱신됩니다. 저장된 토큰은 보안상 화면으로 다시 내려보내지 않습니다. 토큰 입력란은 비어 있으며, **변경하지 않고 저장하면 기존 토큰이 유지**됩니다. 새 토큰을 사용할 때만 32자리 값을 입력하세요.

`config.json`은 앱이 자동으로 생성하며, 토큰이 평문으로 저장됩니다. 이 파일은 `.gitignore`에 포함되어 있으므로 저장소에 올라가지 않습니다.

## 6. 주요 기능

- 실시간 상태, 배터리, 청소 면적·시간
- 전체 청소 / 방 청소 / 구역 청소
- 청소 모드, 흡입력, 물걸레 습도, 청소 횟수, 청소 경로 설정
- 지도 뷰어, 로봇 위치, 청소 경로 표시
- 가상벽·진입금지 구역, 물걸레 금지 구역
- 카펫 등록 및 카펫별 청소 전략
- 문턱(미닫이 문턱 / 문지방) 등록
- 로봇 설정(카펫, 물걸레 확장, 차일드락, 청소금지 시간, 음성)
- 스테이션 설정(물걸레 세척 간격, 열풍 건조, 자동 먼지 비움)
- 소모품 사용률 확인 및 수명 초기화
- 시스템 / 라이트 / 다크 테마

## 9. 경고

- **비공식 프로젝트입니다.** JONR, Xiaomi, Mi Home과 제휴하거나 보증받은 프로젝트가 아닙니다.
- **토큰은 로봇을 완전히 제어할 수 있는 자격 증명입니다.** `config.json`, `.xc_session.json`, 화면 캡처, 터미널 로그를 공유하지 마세요.
- 서버는 `127.0.0.1`에만 바인딩되며, Host·Origin·요청 헤더를 검사해 다른 사이트에서의 호출을 차단합니다. 포트를 외부에 노출하거나 리버스 프록시 뒤에 두지 마세요.
- 지도·청소 경로·카펫·문턱 저장은 **실제 기기 설정을 변경**합니다.
- 클라우드 지도 기능은 Mi 클라우드 정책, 네트워크 상태, 계정 세션에 의존합니다. 세션이 만료되면 `python app.py --login`을 다시 실행해야 합니다.
- 로봇 모델과 펌웨어 버전에 따라 일부 기능이 동작하지 않거나 다르게 표시될 수 있습니다.
- **이 프로젝트의 코드는 100% AI에 의해 작성되었습니다.** 실제 기기에서 사용하기 전에 코드와 동작을 충분히 검토하세요.
- 소프트웨어는 **있는 그대로(AS IS)** 제공되며, 사용으로 인한 기기 오작동·설정 손실·데이터 손실에 대해 보증하지 않습니다.
